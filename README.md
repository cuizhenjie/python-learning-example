## 🚀 环境配置

```bash
# Python 版本
python3 --version  # 3.14.3

# 虚拟环境
python3 -m venv ~/.venv/py3
source ~/.venv/py3/bin/activate

# 常用依赖
pip install requests
pip install pandas
pip install numpy
```
